# Fashion Landing Page 👗

A fashion-inspired landing page created while learning frontend web development.

## About the Project

This project helped me practice HTML and CSS by creating a modern fashion website layout with bold typography, CSS Grid, a navigation menu, video content, and a circular arrow element.

## Built With

- HTML5
- CSS3
- CSS Grid
- Remix Icon

## Features

- Minimal navigation menu
- Large fashion-inspired typography
- Video section with autoplay and looping
- Responsive units using `vw`
- Modern grid-based layout

## What I Learned

- How to structure a webpage using HTML
- How to arrange sections using CSS Grid
- How to style headings and spacing
- How to embed video content
- How to position elements using CSS

## Future Improvements

- Make the layout fully responsive for mobile
- Improve accessibility
- Refine spacing and typography
- Deploy the website using GitHub Pages
